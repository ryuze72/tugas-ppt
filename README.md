# Tugas PPT — Olahraga (PJOK)

Presentasi web interaktif dengan **transisi Morph** ala PowerPoint (1.4 detik).

## Link
- Repo: https://github.com/ryuze72/tugas-ppt
- Pages (jika aktif): https://ryuze72.github.io/tugas-ppt/
- Klipping: https://ryuze72.github.io/tugas-ppt/klipping.html

## File lokal lengkap
Download dari chat Grok:
- `tugas-olahraga-smooth.html` → ganti nama jadi `index.html` lalu upload ke repo
- `klipping.html` → upload ke repo

### Upload cepat di GitHub
1. Buka https://github.com/ryuze72/tugas-ppt
2. Klik **Add file** → **Upload files**
3. Drag `index.html` dan `klipping.html`
4. Commit changes

## Kontrol presentasi
- **Lanjut / Prev** atau panah keyboard
- **Spasi** = lanjut
- **F** = layar penuh
- Swipe di HP
