# Tugas PPT — Olahraga (PJOK)

Presentasi web interaktif dengan **transisi Morph** ala PowerPoint.

## Buka presentasi
- GitHub Pages: https://ryuze72.github.io/tugas-ppt/
- Atau buka `index.html` di browser

## File
- `index.html` — kerangka presentasi
- `style.css` — gaya & animasi
- `app.js` — navigasi & Morph Engine
- `klipping.html` — halaman klipping

## Kontrol
- **Lanjut / Prev** atau panah keyboard
- **Spasi** = lanjut
- **F** = layar penuh
- Swipe di HP
